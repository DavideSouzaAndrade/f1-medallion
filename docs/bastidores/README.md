# Bastidores

Registros internos da equipe durante o desenvolvimento: planos, passagens de
trabalho entre as frentes, notas de estudo e o roteiro da apresentação. Não
são necessários para entender o sistema; para isso, ver
[docs/arquitetura.md](../arquitetura.md).

Cada um retrata o momento em que foi escrito. O que eles dizem sobre o
estado do código pode ter mudado depois; a referência atual são os contratos
e os READMEs de cada componente.
